# Minimal app icon

Created with the built-in imagegen tool. Source artwork: `app-icon-minimal.png`.
The AppIcon asset catalog contains downscaled copies for macOS.

The current native icon uses `app-icon-fullbleed.png` as its source. Its opaque
1024 × 1024 layer is stored in `VG Sentence Mining/AppIcon.icon/Assets/artwork.png`.
macOS applies the outer shape. The original inset artwork remains for reference
and in the legacy asset catalog.

Prompt:

Use case: logo-brand. Asset type: final macOS app icon for VG Sentence Mining, an app for learning words from game dialogue. Create one minimal, precise, nearly flat icon as a square 1024 by 1024 PNG. Centered deep cobalt blue rounded-square tile occupying 88 percent of the canvas, smooth macOS-style continuous rounded corners, genuinely transparent outside the tile. On the tile one simple solid white rounded rectangular speech bubble with a short tail at bottom left. Inside the white bubble, one small blue plus-shaped game directional pad on the left and two short blue horizontal dialogue strokes on the right. All shapes bold, clean, geometric, balanced, generous negative space, instantly readable at 32 pixels. Use only blue and white. No text, no letters, no face, no quotation marks, no extra objects, no bevel, no gloss, no texture, no border, no perspective, no mockup. Subtle tonal shift in blue allowed but almost flat.

Full-bleed edit prompt (built-in imagegen, original minimal icon as reference):

Edit the provided icon artwork for Apple's native app icon format. Preserve the existing crisp white speech bubble, its game directional pad plus sign and two blue horizontal dialogue lines. Change only the framing/background: extend the existing cobalt blue background all the way to all FOUR EDGES and all FOUR CORNERS of the square image. The entire image must be opaque. No rounded tile outline, no transparency, no padding, no inset square, no frame, no border, no outer shadow. It is one solid full-bleed blue square canvas with the same white bubble centered in it at its existing size. Apple applies the outer rounded mask later. High-resolution, exceptionally clean geometric edges, smooth flat blue and white. Output a square image at least 1024 pixels across.
